# Research

This directory contains the core research hypothesis and the implementations of Boltzmann Machines used in this project.

## Contents

- **research_hypothesis/**: Physics-Informed RBMs for PDE Reconstruction hypothesis and plan.
- **boltzmann_machine/**: Implementation of Normal (Classic) Boltzmann Machines from scratch.
- **restricted_boltzmann/**: Implementation of Restricted Boltzmann Machines (RBM) from scratch.
